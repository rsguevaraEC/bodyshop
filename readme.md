## 📌 Descripción general



**Bodyshop** es una aplicación desarrollada en \*\*Microsoft Power Apps\*\* para administrar la operación de talleres automotrices, incluyendo:


\- Gestión de empresas

\- Gestión de talleres

\- Inventario de materiales

\- Movimientos de materiales

\- Órdenes de trabajo

\- Clientes y vehículos

\- Reportes operativos y administrativos



El proyecto combina:

\- Power Apps (interfaz y lógica de negocio)

\- PostgreSQL (base de datos)

\- Azure Database for PostgreSQL Flexible Server (entorno cloud)

\- GitHub (control de versiones y respaldo)



\---



\## 🏗️ Arquitectura del sistema



\### \*\*Frontend\*\*

\- Microsoft Power Apps (Canvas App)

\- Diseño móvil (Phone layout)

\- Futuras pantallas para PC (Tablet/Web layout)



\### \*\*Backend\*\*

\- PostgreSQL 16

\- Azure Flexible Server

\- Esquema principal: `bodyshop`



\### \*\*Control de versiones\*\*

\- Git + GitHub

\- Exportación de la app como `.msapp`

\- Scripts SQL versionados
